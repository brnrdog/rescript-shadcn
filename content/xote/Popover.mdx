## Usage

```res showLineNumbers
<Popover>
  <Popover.Trigger render={<Button variant=Outline />}>
    {"Open Popover"}
  </Popover.Trigger>
  <Popover.Content>
    <h4 className="leading-none font-medium"> {"Title"} </h4>
    <p className="text-muted-foreground text-sm"> {"Description text here."} </p>
  </Popover.Content>
</Popover>
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from
[`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base).
The component in your project owns the markup and the classes, so you can change
either without losing the behaviour.
