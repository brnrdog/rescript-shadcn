## Usage

```res
<Table>
  <Table.Header>
    <Table.Row>
      <Table.Head> {"Invoice"} </Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body>
    <Table.Row>
      <Table.Cell> {"INV001"} </Table.Cell>
    </Table.Row>
  </Table.Body>
</Table>
```

Rows come from data with `View.For`, which reconciles by key rather than
re-rendering the table:

```res
<View.For
  each={MaybeSignal.reactive(invoices)}
  by={invoice => invoice.invoice}
  render={invoice =>
    <Table.Row>
      <Table.Cell> {invoice.invoice} </Table.Cell>
    </Table.Row>}
/>
```
