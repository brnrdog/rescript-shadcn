## Usage

```res
<HoverCard>
  <HoverCard.Trigger> {"@shadcn"} </HoverCard.Trigger>
  <HoverCard.Content> {"The creator of shadcn/ui."} </HoverCard.Content>
</HoverCard>
```

## Positioning

The content is portaled to the end of `document.body` and positioned against
the trigger, flipping to the opposite side when the preferred one has no room.
Use `side` and `align` to choose the preferred placement, and `sideOffset` /
`alignOffset` to nudge it.

```res
<HoverCard.Content side=Right align=Start sideOffset=8. />
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
