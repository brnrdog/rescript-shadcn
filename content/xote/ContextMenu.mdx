## Usage

```res
<ContextMenu>
  <ContextMenu.Trigger> {"Right click here"} </ContextMenu.Trigger>
  <ContextMenu.Content>
    <ContextMenu.Item> {"Back"} </ContextMenu.Item>
    <ContextMenu.Separator />
    <ContextMenu.Item disabled=true> {"Forward"} </ContextMenu.Item>
  </ContextMenu.Content>
</ContextMenu>
```

The trigger renders a zero-size anchor that follows the pointer, so the menu
opens at the cursor rather than against the trigger's box.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
