## Usage

```res showLineNumbers
<ContextMenu>
  <ContextMenu.Trigger> {"Right click here"} </ContextMenu.Trigger>
  <ContextMenu.Content>
    <ContextMenu.Item> {"Profile"} </ContextMenu.Item>
    <ContextMenu.Item> {"Billing"} </ContextMenu.Item>
    <ContextMenu.Item> {"Team"} </ContextMenu.Item>
    <ContextMenu.Item> {"Subscription"} </ContextMenu.Item>
  </ContextMenu.Content>
</ContextMenu>
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from
[`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base).
The component in your project owns the markup and the classes, so you can change
either without losing the behaviour.
