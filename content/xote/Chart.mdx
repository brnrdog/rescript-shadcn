## Usage

```res
let data: array<Chart.point> = [
  {label: "January", value: 186.},
  {label: "February", value: 305.},
]

<Chart.Bar data ariaLabel="Visitors per month" />
```

Recharts is React-only, so this is a small SVG chart covering the bar and line
shapes, drawn with the theme's `--chart-*` colours.
