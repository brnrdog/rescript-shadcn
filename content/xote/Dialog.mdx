## Usage

```res
<Dialog>
  <Dialog.Trigger> {"Open"} </Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Header>
      <Dialog.Title> {"Are you sure?"} </Dialog.Title>
      <Dialog.Description> {"This action cannot be undone."} </Dialog.Description>
    </Dialog.Header>
  </Dialog.Content>
</Dialog>
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-base-xote`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/base-xote); the component in your project owns the markup and the classes.
