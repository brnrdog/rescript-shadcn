## Usage

```res showLineNumbers
<Avatar>
  <Avatar.Image src="https://github.com/shadcn.png" alt="@shadcn" />
  <Avatar.Fallback> {"CN"} </Avatar.Fallback>
</Avatar>
```

## Examples

### Basic

A basic avatar component with an image and a fallback.

<ComponentPreview name="AvatarBasic" />

### Badge

Use the `Avatar.Badge` component to add a badge to the avatar. The badge is positioned at the bottom right of the avatar.

<ComponentPreview name="AvatarBadge" />

Use the `className` prop to add custom styles to the badge such as custom colors, sizes, etc.

```res showLineNumbers
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
  <AvatarFallback> {"CN"} </AvatarFallback>
  <AvatarBadge className="bg-green-600 dark:bg-green-800" />
</Avatar>
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from
[`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base).
The component in your project owns the markup and the classes, so you can change
either without losing the behaviour.
