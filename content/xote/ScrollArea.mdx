## Usage

```res
<ScrollArea className="h-72 w-48 rounded-md border">
  <div class="p-4"> {"Long content"} </div>
</ScrollArea>
```

This build styles the native scrollbar rather than rendering a custom thumb, so
scrolling stays hardware accelerated and needs no measurement.

## API Reference

This component is plain markup built with [xote](https://xote.dev/) — everything it renders lives in the file you copied.
