## Examples

### Basic

<ComponentPreview name="InputBasic" />

### Field

Use `Field`, `FieldLabel`, and `FieldDescription` to create an input with a
label and description.

<ComponentPreview name="InputField" />

### Field Group

Use `FieldGroup` to show multiple `Field` blocks and to build forms.

<ComponentPreview name="InputFieldgroup" />

### File

Use the `type="file"` prop to create a file input.

<ComponentPreview name="InputFile" />

### Inline

Use `Field` with `orientation="horizontal"` to create an inline input.
Pair with `Button` to create a search input with a button.

<ComponentPreview name="InputInline" />

### Grid

Use a grid layout to place multiple inputs side by side.

<ComponentPreview name="InputGrid" />

### Required

Use the `required` attribute to indicate required inputs.

<ComponentPreview name="InputRequired" />

### Badge

Use `Badge` in the label to highlight a recommended field.

<ComponentPreview name="InputBadge" />

### Input Group

To add icons, text, or buttons inside an input, use the `InputGroup` component. See the [Input Group](/components/InputGroup) component for more examples.

<ComponentPreview name="InputInputGroup" />

### Button Group

To add buttons to an input, use the `ButtonGroup` component. See the [Button Group](/components/ButtonGroup) component for more examples.
