## Usage

```res
<ToggleGroup multiple=true defaultValue=["bold"] variant=Outline>
  <ToggleGroup.Item value="bold" ariaLabel="Bold"> {"B"} </ToggleGroup.Item>
  <ToggleGroup.Item value="italic" ariaLabel="Italic"> {"I"} </ToggleGroup.Item>
</ToggleGroup>
```

Leave `multiple` off for a single-select group, which then exposes itself as a
radio group.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
