## Usage

```res
<DropdownMenu>
  <DropdownMenu.Trigger> {"Open"} </DropdownMenu.Trigger>
  <DropdownMenu.Content>
    <DropdownMenu.Label> {"My Account"} </DropdownMenu.Label>
    <DropdownMenu.Separator />
    <DropdownMenu.Item onSelect={() => Console.log("profile")}>
      {"Profile"}
      <DropdownMenu.Shortcut> {"⇧⌘P"} </DropdownMenu.Shortcut>
    </DropdownMenu.Item>
  </DropdownMenu.Content>
</DropdownMenu>
```

The trigger opens on click or with the arrow keys; inside, the arrow keys move
between items, Home and End jump to the ends, Enter activates, and Escape or a
press outside closes and returns focus to the trigger.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
