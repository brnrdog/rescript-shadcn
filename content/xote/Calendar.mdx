`mode` is `Single`, `Multiple` or `Range`. Each mode manages its own selection
when you pass nothing, so `<Calendar mode=Range />` works on its own; pass
`selected` / `selectedDates` / `selectedRange` with the matching `onSelect*` to
drive it yourself. Range days carry `data-range="start" | "middle" | "end"`.

The React registries use react-day-picker, which has no framework-agnostic core,
so this is a month grid written against `Date`.

## Usage

```res
let selected = Signal.make(Some(Date.make()))

<Calendar
  selected={MaybeSignal.reactive(selected)}
  onSelect={date => Signal.set(selected, Some(date))}
/>
```

The React registries use react-day-picker, which has no framework-agnostic core,
so this is a month grid written against `Date`: six rows always, so the grid
never changes height between months.
