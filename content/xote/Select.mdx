## Usage

```res showLineNumbers
<Select>
  <Select.Trigger className="w-[180px]">
    <Select.Value placeholder="Theme" />
  </Select.Trigger>
  <Select.Content>
    <Select.Group>
      <Select.Item value="light"> {"Light"} </Select.Item>
      <Select.Item value="dark"> {"Dark"} </Select.Item>
      <Select.Item value="system"> {"System"} </Select.Item>
    </Select.Group>
  </Select.Content>
</Select>
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from
[`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base).
The component in your project owns the markup and the classes, so you can change
either without losing the behaviour.
