## Usage

```res
Toast.add(~title="Event created", ~description="Sunday at 9:00 AM")->ignore

// Render the viewport once, near the root of your app:
<Toast.Toaster />
```

The store is module level, so `Toast.add` works from anywhere without a provider
in scope. Pass `~duration=0` for a toast that stays until dismissed.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
