## Usage

```res
<Drawer>
  <Drawer.Trigger> {"Open"} </Drawer.Trigger>
  <Drawer.Content direction=Bottom>
    <Drawer.Header>
      <Drawer.Title> {"Move goal"} </Drawer.Title>
      <Drawer.Description> {"Set your daily activity goal."} </Drawer.Description>
    </Drawer.Header>
  </Drawer.Content>
</Drawer>
```

The drawer is a dialog pinned to an edge, chosen with `direction`. Dragging it
shut is not implemented — it closes through its actions, Escape or the overlay.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
