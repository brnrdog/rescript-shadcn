## Usage

```res
<Command>
  <Command.Input placeholder="Type a command or search..." />
  <Command.List>
    <Command.Empty> {"No results found."} </Command.Empty>
    <Command.Group heading="Suggestions">
      <Command.Item value="Calendar" onSelect={() => Console.log("calendar")}>
        {"Calendar"}
      </Command.Item>
    </Command.Group>
  </Command.List>
</Command>
```

Items register their `value` as searchable text; typing hides the ones that do
not match, and `Command.Empty` appears when none do.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
