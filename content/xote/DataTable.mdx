## Usage

```res
let columns: array<DataTable.column<payment>> = [
  DataTable.column(~key="email", ~header="Email", ~value=payment => payment.email),
  DataTable.column(~key="amount", ~header="Amount", ~value=payment => payment.amount),
]

<DataTable rows=payments columns rowKey={payment => payment.id} />
```

Sorting and filtering are signals over the row array rather than a table
library: click a header to sort, and pass a `filter` signal to narrow the rows.
