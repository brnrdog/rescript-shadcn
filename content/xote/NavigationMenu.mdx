## Usage

```res showLineNumbers
<NavigationMenu>
  <NavigationMenu.List>
    <NavigationMenu.Item>
      <NavigationMenu.Trigger> {"Item One"} </NavigationMenu.Trigger>
      <NavigationMenu.Content>
        <NavigationMenu.Link> {"Link"} </NavigationMenu.Link>
      </NavigationMenu.Content>
    </NavigationMenu.Item>
  </NavigationMenu.List>
</NavigationMenu>
```

## Link Component

Use the `render` prop to compose a custom link component such as Next.js `Link`.

```res showLineNumbers

module NavigationMenuDemo = {
  @react.component
  let make = () =>
    <NavigationMenu.Item>
      <NavigationMenu.Link
        render={<Next.Link href="/docs" />}
        className={NavigationMenu.navigationMenuTriggerStyle()}
      >
        Documentation
      </NavigationMenuLink>
    </NavigationMenuItem>
}
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from
[`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base).
The component in your project owns the markup and the classes, so you can change
either without losing the behaviour.
