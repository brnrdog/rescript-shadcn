## Usage

```res
<Combobox>
  <Combobox.Trigger> {"Select framework..."} </Combobox.Trigger>
  <Combobox.Content>
    <Combobox.Input placeholder="Search framework..." />
    <Combobox.List>
      <Combobox.Empty> {"No framework found."} </Combobox.Empty>
      <Combobox.Item value="Next.js" onSelect={() => Console.log("next")}>
        {"Next.js"}
      </Combobox.Item>
    </Combobox.List>
  </Combobox.Content>
</Combobox>
```

A popover holding a command list, so filtering, empty state and grouping behave
exactly as they do in `Command`.
