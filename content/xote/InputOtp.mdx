## Usage

```res
<InputOtp length=6 onComplete={code => Console.log(code)}>
  <InputOtp.Group>
    <InputOtp.Slot index=0 />
    <InputOtp.Slot index=1 />
    <InputOtp.Slot index=2 />
  </InputOtp.Group>
  <InputOtp.Separator />
  <InputOtp.Group>
    <InputOtp.Slot index=3 />
    <InputOtp.Slot index=4 />
    <InputOtp.Slot index=5 />
  </InputOtp.Group>
</InputOtp>
```

A single real input holds the value and the slots render from it, so paste,
autofill and the numeric keyboard on mobile all keep working.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
