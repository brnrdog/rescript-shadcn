## Usage

```res
<Accordion defaultValue=["item-1"]>
  <Accordion.Item value="item-1">
    <Accordion.Trigger> {"Is it accessible?"} </Accordion.Trigger>
    <Accordion.Content> {"Yes. It follows the WAI-ARIA pattern."} </Accordion.Content>
  </Accordion.Item>
</Accordion>
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-base-xote`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/base-xote); the component in your project owns the markup and the classes.
