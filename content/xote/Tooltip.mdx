## Usage

```res showLineNumbers
<Tooltip>
  <Tooltip.Trigger render={<Button variant=Outline />}>
    {"Hover"}
  </Tooltip.Trigger>
  <Tooltip.Content>
    <p> {"Add to library"} </p>
  </Tooltip.Content>
</Tooltip>
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from
[`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base).
The component in your project owns the markup and the classes, so you can change
either without losing the behaviour.
