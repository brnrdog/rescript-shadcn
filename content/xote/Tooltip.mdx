## Usage

```res
<Tooltip>
  <Tooltip.Trigger> {"Hover me"} </Tooltip.Trigger>
  <Tooltip.Content> {"Add to library"} </Tooltip.Content>
</Tooltip>
```

## Positioning

The content is portaled to the end of `document.body` and positioned against
the trigger, flipping to the opposite side when the preferred one has no room.
Use `side` and `align` to choose the preferred placement, and `sideOffset` /
`alignOffset` to nudge it.

```res
<Tooltip.Content side=Right align=Start sideOffset=8. />
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-base-xote`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/base-xote); the component in your project owns the markup and the classes.
