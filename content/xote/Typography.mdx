## Usage

```res
<h1 class="scroll-m-20 text-4xl font-extrabold tracking-tight text-balance">
  {"The Joke Tax Chronicles"}
</h1>
```

Typography is not a component — it is a set of classes you apply to plain
elements. The preview above shows the headings, lead, blockquote, list and
inline code styles the theme defines.

## API Reference

This component is plain markup built with [xote](https://xote.dev/) — everything it renders lives in the file you copied.
