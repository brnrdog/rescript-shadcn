## Usage

```res showLineNumbers
<Sheet>
  <Sheet.Trigger render={<Button variant=Outline />}>
    {"Open"}
  </Sheet.Trigger>
  <Sheet.Content>
    <Sheet.Header>
      <Sheet.Title> {"Are you absolutely sure?"} </Sheet.Title>
      <Sheet.Description> {"This action cannot be undone."} </Sheet.Description>
    </Sheet.Header>
  </Sheet.Content>
</Sheet>
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from
[`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base).
The component in your project owns the markup and the classes, so you can change
either without losing the behaviour.
