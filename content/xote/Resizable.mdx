## Usage

```res
<Resizable defaultRatio=40.>
  <Resizable.Panel> {"Sidebar"} </Resizable.Panel>
  <Resizable.Handle withHandle=true />
  <Resizable.Panel grow=true> {"Content"} </Resizable.Panel>
</Resizable>
```

The handle writes a percentage into a CSS variable on the group, so a drag is a
single style write rather than a re-render. Arrow keys nudge it by 2%.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
