## About

The `Resizable` component is built on top of [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels) by [bvaughn](https://github.com/bvaughn).

## Usage

```res showLineNumbers
<Resizable orientation=Horizontal>
  <Resizable.Panel> {"One"} </Resizable.Panel>
  <Resizable.Handle />
  <Resizable.Panel> {"Two"} </Resizable.Panel>
</Resizable>
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from
[`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base).
The component in your project owns the markup and the classes, so you can change
either without losing the behaviour.
