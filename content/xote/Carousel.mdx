## Usage

```res
<Carousel>
  <Carousel.Content>
    <Carousel.Item> {"Slide 1"} </Carousel.Item>
    <Carousel.Item> {"Slide 2"} </Carousel.Item>
  </Carousel.Content>
  <Carousel.Previous />
  <Carousel.Next />
</Carousel>
```

Motion is CSS scroll-snap rather than a JS animation loop, so there is no
per-frame work and touch and trackpad gestures come for free. Pass
`orientation=Vertical` to snap up and down instead.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
