## Usage

```res
<MessageScroller>
  <MessageScroller.Item> {"Message"} </MessageScroller.Item>
</MessageScroller>
```

New content scrolls into view only while the reader is already at the bottom, so
scrolling up is never yanked away. The button jumps back to the latest message.

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from [`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base); the component in your project owns the markup and the classes.
