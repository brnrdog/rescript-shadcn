## Usage

```res showLineNumbers
<Collapsible>
  <Collapsible.Trigger render={<Button variant=Ghost size=Icon />}>
    <Icons.ChevronsUpDown />
  </Collapsible.Trigger>
  <Collapsible.Content>
    {"Content here."}
  </Collapsible.Content>
</Collapsible>
```

## Controlled State

Use the `open` and `onOpenChange` props to control the state.

```res showLineNumbers
@react.component
let make = () => {
  let open_ = Signal.make(false)

  <Collapsible open_= onOpenChange={o => setOpen(_ => o)}>
    <CollapsibleTrigger> {"Toggle"} </CollapsibleTrigger>
    <CollapsibleContent> {"Content"} </CollapsibleContent>
  </Collapsible>
}
```

## API Reference

Behaviour, ARIA wiring and keyboard interaction come from
[`rescript-xote-base`](https://github.com/miriadhq/rescript-shadcn/tree/main/packages/xote-base).
The component in your project owns the markup and the classes, so you can change
either without losing the behaviour.
